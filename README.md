# BU CS Foundations Bootcamp

A collection of my coursework from Boston University's Online AI Programs
CS Foundations Bootcamp.

## Repository Layout

- module1/ : Setting up the dev environment and writing initial Java programs
- module2/ : Core programming concepts (variables, control flow, methods, file I/O)
- module3/ : Introduction to data structures and object-oriented programming

## Programs

Every module directory holds the Java source files produced during that
module's activities.
